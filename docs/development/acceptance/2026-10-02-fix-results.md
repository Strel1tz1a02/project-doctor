## 目标接入约定

目标侧读取 X-Project-Doctor-Request-Id，保存于请求上下文，每条 SQL 标记为：

```text
/* pd:<仓库相对路径>:<行号> request=<32 位十六进制 ID> */ SELECT ...
```

请求结束时清理上下文；异步任务须显式传播上下文。仅有旧代码位置标记不构成请求关联。平台同时在查询与解析阶段核验 ID。
